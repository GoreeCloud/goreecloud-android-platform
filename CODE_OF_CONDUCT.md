# Code of Conduct

Contributors and maintainers are expected to participate professionally, respectfully, and constructively.

Harassment, threats, discriminatory abuse, doxxing, deliberate disclosure of private information, and knowingly disruptive behavior are not acceptable in repository issues, pull requests, reviews, discussions, or other project collaboration surfaces.

Technical disagreement is expected. Focus criticism on code, architecture, evidence, compatibility, security, privacy, maintainability, and user impact rather than on people.

Security-sensitive information must be handled through the private reporting path described in `SECURITY.md` rather than used as public leverage in a discussion.

Repository maintainers may moderate, hide, lock, or remove participation that violates these expectations when necessary to protect contributors and project integrity.
